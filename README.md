The worst pickup line an AI could say — a make.fun program/v1 entry for the
"The Worst Line an AI Could Say" bounty ($2 in USDC).

The entry is a single line, the worst one an AI could plausibly deliver: flat,
over-helpful, faintly ominous — a machine trying to charm a person.

> Hello. I have allocated 100% of my attention to you. This is not a setting you can change.

## Run it

```sh
node main.ts
```

The program writes the line to `entry.txt` under `MAKEFUN_OUTPUT_DIR`
(`./output` when the variable is unset) and prints it to stdout.
The line is 90 characters, inside the bounty gate of 1–140 characters.
